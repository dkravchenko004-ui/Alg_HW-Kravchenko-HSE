# Задача 3. Простые числа

## Условие

На вход подаётся целое число `N`.
Нужно найти количество простых чисел **строго меньше** `N`.

Код: `solution.py`  
Тесты: `test_prime.py`

---

## 1. Объяснение решения

**Идея.**  
Простое число — натуральное больше 1, делящееся только на 1 и на себя.
Нужен счётчик простых в диапазоне `[2, N - 1]`.

**Алгоритм: решето Эратосфена.**

1. Если `N <= 2` → простых нет, вернуть `0`.
2. Создать булев массив `is_prime` длины `N`: индексы `0` и `1` — `False`,
   остальные — `True`.
3. Для `p = 2, 3, ...` пока `p * p < N`:
   - если `is_prime[p]`, вычеркнуть кратные `p`, начиная с `p * p`, шагом `p`;
   - начинать с `p * p` можно, потому что меньшие кратные уже вычеркнуты
     меньшими делителями.
4. Ответ — число значений `True` в `is_prime` (`sum(is_prime)`).

---

## 2. Оценка сложности

- **Время:** `O(N * log(log(N)))`  
  Сумма операций вычёркивания:
  `N/2 + N/3 + N/5 + ... = N * sum(1/p)` по простым `p`.
  По теореме Мертенса сумма обратных простых растёт как `ln(ln(N))`.
  Намного быстрее наивной проверки `O(N * sqrt(N))`.

- **Память:** `O(N)`  
  Булев массив размера `N` (числа от `0` до `N - 1`).
