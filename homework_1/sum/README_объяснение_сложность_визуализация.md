# Задача 2. Сумма

## Условие

На вход подаётся массив целых положительных чисел, разделённых пробелом.
Нужно найти максимальную сумму элементов массива, которая делится на 2.

Код: `solution.py`  
Тесты: `test_sum.py`

---

## 1. Объяснение решения

**Идея алгоритма.**  
Нужно выбрать подмножество положительных чисел с **максимальной чётной** суммой.

**Обоснование.**

1. Все `x > 0`, поэтому добавление числа всегда увеличивает сумму.
   Максимум ограничен суммой всех элементов: `total_sum = sum(arr)`.
2. Чётность суммы зависит только от числа нечётных слагаемых:
   сумма чётна тогда и только тогда, когда число нечётных элементов чётно.

**Жадный выбор.**

- Если `total_sum % 2 == 0` — сумма всех элементов уже чётна и максимальна.
  Ответ: `total_sum`.
- Если `total_sum % 2 != 0` — нужно убрать нечётную сумму.
  Минимальная потеря — исключить **одно** минимальное нечётное число:
  `total_sum - min_odd`.
- Пример `[3]`: `3 - 3 = 0`. Пустая сумма равна `0`, а `0` делится на 2 —
  согласуется с условием.

---

## 2. Оценка сложности

- **Время:** `O(N)`  
  Один проход по массиву: сумма и поиск `min_odd`. Парсинг строки — тоже `O(N)`.

- **Память:** `O(N)` на список при разборе строки  
  (или `O(1)` дополнительной памяти, если массив уже в памяти / поток).

---

## 3. Визуализация работы алгоритма

Пример: `"5 7 13 2 14"` => массив `[5, 7, 13, 2, 14]`.

| Шаг | Элемент | Чётность | total_sum | min_odd      |
|----:|--------:|----------|----------:|--------------|
| 1   | 5       | нечётное | 5         | 5            |
| 2   | 7       | нечётное | 12        | min(5, 7)=5  |
| 3   | 13      | нечётное | 25        | min(5, 13)=5 |
| 4   | 2       | чётное   | 27        | 5            |
| 5   | 14      | чётное   | 41        | 5            |

- `total_sum = 41` (нечётно), `min_odd = 5`
- ответ: `41 - 5 = 36`
- выбранные элементы: `[2, 7, 13, 14]`, сумма `36`

**Контрпример 1:** `"3"` => `3 - 3 = 0`.

**Контрпример 2:** `"2 4 6 8"` => сумма `20` уже чётна → ответ `20`.
