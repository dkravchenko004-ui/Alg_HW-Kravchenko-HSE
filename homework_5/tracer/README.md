# Задача 1. Tracer

## Условие

Реализовать декоратор, который показывает стек вызовов рекурсивных функций.
На каждом шаге видно вход в рекурсию, отступ по глубине стека и возврат
с результатом.

Код: `solution.py`  
Тесты: `test_tracer.py`

---

## 1. Объяснение решения

Декоратор `trace` оборачивает функцию. Перед вызовом печатает `-> имя(аргументы)`
с отступом `2 * глубина` пробела. Глубину увеличиваем, вызываем исходную
функцию, глубину уменьшаем, печатаем `<- имя(аргументы) = результат`.

Рекурсивный вызов идёт уже в обёртку, поэтому каждый уровень стека даёт
свою пару строк. `try/finally` нужен, чтобы при исключении глубина не
залипла.

`functools.wraps` оставляет исходное имя функции — в печати будет
`factorial`, а не `wrapper`.

---

## 2. Оценка сложности

Пусть функция без декоратора работает время `T` и делает `K` вызовов.

- **Время:** `O(T + K)`. На каждый вызов добавляется печать аргументов
  и результата. Для коротких аргументов это константа на вызов.
- **Память:** `O(1)` сверх стека самой рекурсии. Глубина хранится одним
  числом `trace.depth`.

Декоратор не меняет асимптотику алгоритма, который им обернули.

---

## 3. Визуализация работы алгоритма

`factorial(3)`: `3 * 2 * 1`.

```text
-> factorial(3)
  -> factorial(2)
    -> factorial(1)
    <- factorial(1) = 1
  <- factorial(2) = 2
<- factorial(3) = 6
```

Сначала спуск: каждый следующий `->` правее. На `n = 1` рекурсия
останавливается. Потом подъём: на каждом уровне видно, какой результат
ушёл наверх. `factorial(2)` вернул `2`, потому что `2 * 1`. Снаружи
`3 * 2 = 6`.
