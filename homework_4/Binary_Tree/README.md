# Binary Tree

Три задачи про бинарные деревья: BST и обходы, проверка BST, баланс по высоте.

В каждой задаче есть:

- `solution.py` — код решения
- `test_*.py` — тесты (`unittest`)
- `README.md` — идея алгоритма, оценка сложности `O(...)`, визуализация дерева

## Структура

```text
homework_4/Binary_Tree/
├── README.md
├── tree_traversal/
├── validate_bst/
└── balanced_tree/
```

## Задачи

| Папка | Задача | Кратко |
| ----- | ------ | ------ |
| [tree_traversal/](tree_traversal/) | Tree Traversal | BST, вставка, шесть обходов |
| [validate_bst/](validate_bst/) | Validate BST | дерево является BST или нет |
| [balanced_tree/](balanced_tree/) | Balanced Binary Tree | баланс по высоте |

Подробности — в `README.md` соответствующей папки.

Как запускать тесты — в [корневом README homework_4](../README.md).
