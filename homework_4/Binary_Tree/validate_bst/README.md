# Задача 2. Validate BST

## Условие

Проверить, является ли произвольное бинарное дерево корректным деревом
поиска (BST). Ответ — `True` или `False`.

Код: `solution.py`  
Тесты: `test_validate_bst.py`

---

## 1. Объяснение решения

**Идея.** Недостаточно сравнить узел только с двумя детьми. Нарушение может
сидеть глубже: правый ребёнок тройки равен 6, при родителе 5 это уже не BST,
хотя у пятёрки левый ребёнок 3 меньше её.

Поэтому каждому поддереву передаём допустимый интервал ключа.

- Идём налево — всё, что там, должно быть **строго меньше** текущего узла:
  верхняя граница становится `node.value`.
- Идём направо — всё, что там, **не меньше** текущего (равные кладём вправо,
  как во вставке задачи 1): нижняя граница становится `node.value`.

Пустое дерево и один узел — корректные BST.

Проверка «левый < узел < правый» только на детях пропускает как раз случай
с шестёркой внутри левого поддерева. Интервал это ловит: у узла 6 нижняя
граница не задана локально, а верхняя уже `5`, и `6 >= 5`.

**Некорректный ввод.** Не узел дерева — `TypeError`. Значение узла не целое —
тоже `TypeError`.

---

## 2. Оценка сложности

Пусть `N` — число узлов, `H` — высота.

- **Время:** `O(N)`. Каждый узел смотрим один раз, сравнение с границами
  константное.
- **Память:** `O(H)` на стек рекурсии. В сбалансированном дереве это
  `O(log N)`, в цепочке `O(N)`.

---

## 3. Визуализация работы алгоритма

Дерево, которое «с виду» похоже на BST, но не является им:

```text
      5
     / \
    3   7
     \
      6
```

У 5 дети 3 и 7 — локально нормально. Шестёрка больше пятёрки, хотя стоит
в левом поддереве.

| Узел | интервал ключа     | ок? | Почему |
| ---- | ------------------ | --- | ------ |
| 5    | (−∞, +∞)           | да  | корень без границ |
| 3    | (−∞, 5)            | да  | 3 < 5 |
| 6    | [3, 5)             | нет | 6 ≥ 5, вышли за верх |
| 7    | сюда уже не идём   |     | левая ветка уже сломалась |

Функция возвращает `False`.

Корректный соседний пример — дерево из задачи 1:

```text
            8
           / \
          3   10
         / \    \
        1   6    14
           / \
          4   7
```

У шестёрки интервал `[3, 8)`: и 4, и 7 в него попадают. У 14 интервал
`[10, +∞)`. Всё сходится, ответ `True`.
