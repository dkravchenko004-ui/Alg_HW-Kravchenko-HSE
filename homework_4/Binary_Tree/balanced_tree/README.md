# Задача 3. Balanced Binary Tree

## Условие

Определить, сбалансировано ли бинарное дерево по высоте. Дерево
сбалансировано, если **у каждого узла** высоты левого и правого
поддеревьев отличаются не больше чем на 1. Ответ — `True` или `False`.

Код: `solution.py`  
Тесты: `test_balanced_tree.py`

---

## 1. Объяснение решения

Высота пустого дерева — 0, высота листа — 1.

Наивный способ: для каждого узла отдельно посчитать две высоты и вычесть.
Тогда одни и те же поддеревья считаются много раз, время `O(N^2)`.

Здесь один обход снизу вверх. Функция `_height` для узла:

1. считает высоту левого ребёнка;
2. считает высоту правого;
3. если где-то уже нашли перекос, возвращает `-1` как сигнал «не

   сбалансировано»;
4. если `|left - right| > 1` — тоже `-1`;
5. иначе высота узла это `1 + max(left, right)`.

`is_balanced` просто смотрит, что высота корня не `-1`.

Важно проверять **каждый** узел, не только корень. Бывает, что дети
сбалансированы, а у корня разница высот уже 2.

Пустое дерево и один узел считаем сбалансированными.

**Некорректный ввод.** Не узел дерева — `TypeError`.

---

## 2. Оценка сложности

Пусть `N` — число узлов, `H` — высота.

- **Время:** `O(N)`. Каждый узел посещаем один раз.
- **Память:** `O(H)` на стек рекурсии.

---

## 3. Визуализация работы алгоритма

Сначала дерево, которое ещё проходит (разница высот у корня равна 1):

```text
      1            высоты:
     / \             лист 4 => 1
    2   3            узел 2 => 2
   /                 узел 3 => 1
  4                  узел 1 => |2-1| = 1  => True
```

Теперь пример, где дети в порядке, а корень нет:

```text
        1
       / \
      2   3
     / \
    4   5
   /
  6
```

```text
узел  слева  справа  |разница|  вывод
6     0      0       0          лист, высота 1
4     1      0       1          ок, высота 2
5     0      0       0          высота 1
2     2      1       1          ок, высота 3
3     0      0       0          высота 1
1     3      1       2          слишком, -1
```

У узла 2 условие ещё выполняется. Ломается корень: левое поддерево
глубины 3, правое — лист. Ответ `False`.
