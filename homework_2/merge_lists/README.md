# Задача 3. Merge lists

## Условие

Даны два отсортированных односвязных списка `list1` и `list2`.
Нужно объединить их в один отсортированный список и вернуть голову.
Новый список собирается из узлов двух исходных (значения в новые узлы
не копируем).

Пример: `list1 = [1, 2, 4]`, `list2 = [1, 3, 4]` -> `[1, 1, 2, 3, 4, 4]`.

Нужны два способа: с фиктивным элементом и без него.

Код: `solution.py`  
Тесты: `test_merge_lists.py`

---

## 1. Объяснение решения

**Идея алгоритма.**  
Списки уже отсортированы. Сравниваем текущие головы и в результат
отправляем меньший узел. Так пока оба списка не кончатся. Остаток
второго списка просто прицепляем в конец: он и так идёт по возрастанию.

Ссылки `next` переставляем у существующих узлов, новые узлы с числами
не создаём.

Если значения равны, берём узел из `list1` (сравнение `<=`).

### Способ 1. С фиктивным элементом

Создаём служебный узел `dummy`. Он не входит в ответ, но за него удобно
«держать» список с самого начала: не надо отдельно решать, какая голова
будет первой.

Указатель `tail` всегда стоит на последнем уже собранном узле
(сначала это `dummy`):

- пока оба списка непусты, к `tail.next` цепляем меньшую голову
и сдвигаем этот список вперёд, затем `tail = tail.next`;
- когда один список кончился: `tail.next =` оставшийся список.

Ответ — `dummy.next`.

### Способ 2. Без фиктивного элемента

Если один из списков пустой, возвращаем второй.

Иначе сами выбираем голову: меньшая из двух первых вершин.
Дальше тот же цикл, что и с `dummy`, но `tail` сразу указывает
на эту настоящую голову.

Кода чуть больше (отдельно обрабатываем пустые списки и выбор головы),
зато нет лишнего узла.

**Некорректный ввод.**  
Пустой список — штатный случай, не ошибка: возвращаем второй список
(или `None`, если оба пусты). `TypeError` бросает только `from_list`,
если в последовательность попало не целое число.

---



## 2. Оценка сложности

Пусть длины списков — `N` и `M`. Оба способа одинаковы по сложности.

- **Время:** `O(N + M)`.  
Каждый узел смотрим один раз.
- **Память:** `O(1)` дополнительно.  
Нужны только указатели (`dummy` или `head`, `tail`, текущие головы).
Фиктивный узел — один объект, это тоже `O(1)`.

## 3. Визуализация работы алгоритма



### Нетривиальный пример: разная длина, хвост целиком

Не из условия. Здесь видно главное отличие от «всегда сравнивать»:
когда один список кончился, остаток второго прицепляется одним присваиванием.

```text
list1:  A(1) -> B(8)
list2:  C(2) -> D(3) -> E(4) -> F(5)
```

С фиктивным элементом:

```text
Шаг  Сравниваем   Берём  Что уже собрали                 list1  list2
---  -----------  -----  ------------------------------  -----  -----------
1    A(1) и C(2)  A      dummy -> A                      B      C
2    B(8) и C(2)  C      dummy -> A -> C                 B      D
3    B(8) и D(3)  D      dummy -> A -> C -> D            B      E
4    B(8) и E(4)  E      dummy -> A -> C -> D -> E       B      F
5    B(8) и F(5)  F      dummy -> A -> C -> D -> E -> F  B      —
6    list2 пуст   хвост  ... -> F -> B                   —      —
```

На шаге 6 сравнений больше нет: `tail.next = B`, и за `B` уже идёт
всё, что осталось в `list1`. Результат: `[1, 2, 3, 4, 5, 8]`.

Без dummy то же самое, только шаг 0 выбирает голову `A` сам,
а не через `dummy.next`.

### Пример из условия: оба способа

Пометим узлы буквами, чтобы было видно, что это те же объекты, а не копии:

```text
list1:  A(1) -> B(2) -> C(4)
list2:  D(1) -> E(3) -> F(4)
```



#### С фиктивным элементом

Старт: `dummy`, `tail = dummy`.

```text
Шаг  Сравниваем    Берём  Что уже собрали                        list1  list2
---  ------------  -----  -------------------------------------  -----  -----
1    A(1) и D(1)   A      dummy -> A                             B      D
2    B(2) и D(1)   D      dummy -> A -> D                        B      E
3    B(2) и E(3)   B      dummy -> A -> D -> B                   C      E
4    C(4) и E(3)   E      dummy -> A -> D -> B -> E              C      F
5    C(4) и F(4)   C      dummy -> A -> D -> B -> E -> C         —      F
6    list1 пуст    хвост  dummy -> A -> D -> B -> E -> C -> F    —      —
```

Ответ: `dummy.next` -> значения `[1, 1, 2, 3, 4, 4]`.

#### Без фиктивного элемента

Оба списка непусты, `A(1) <= D(1)`, поэтому `head = A`, дальше работаем
с остатком `B -> C` и `D -> E -> F`.

```text
Шаг  Сравниваем   Берём  Что уже собрали                  остаток list1  остаток list2
---  -----------  -----  -------------------------------  -------------  -------------
0    A и D        A      A (это голова)                   B              D
1    B и D        D      A -> D                           B              E
2    B и E        B      A -> D -> B                      C              E
3    C и E        E      A -> D -> B -> E                 C              F
4    C и F        C      A -> D -> B -> E -> C            —              F
5    list1 пуст   хвост  A -> D -> B -> E -> C -> F       —              —
```

Голова — узел `A`, не `dummy`. Значения те же: `[1, 1, 2, 3, 4, 4]`.

### Граница: пустой список

`list1` пуст, `list2 = [0]`.

- с dummy: цикл не крутится, к хвосту сразу цепляется `list2`;
- без dummy: срабатывает проверка `if list1 is None: return list2`.
