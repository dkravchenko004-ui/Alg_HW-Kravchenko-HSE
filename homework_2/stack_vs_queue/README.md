# Задача 1. Stack vs Queue

## Условие

Реализовать стек и очередь на основе связных списков. Без сторонних библиотек.

Код: `solution.py`  
Тесты: `test_stack_vs_queue.py`

---

## 1. Объяснение решения

**Идея алгоритма.**  
Обе структуры хранятся в односвязном списке. Узел — это значение и ссылка `next`.
Отличается только то, с какого конца мы вставляем и удаляем.

**Стек (последний пришёл — первый ушёл).**  
Вершина стека — голова списка `_head`.

1. `push(x)` — создаём узел, он указывает на старую голову и сам становится головой.
2. `pop()` — возвращаем значение головы и сдвигаем `_head` на следующий узел.
3. `peek()` — смотрим на голову, но не удаляем её.

Так меняется только начало списка, поэтому `push` и `pop` не ходят по всем элементам.

**Очередь (первый пришёл — первый ушёл).**  
Удалять нужно с начала, добавлять в конец. Одного указателя мало: чтобы дойти
до конца списка, пришлось бы каждый раз проходить все узлы. Поэтому два указателя:

- `_head` — откуда забираем элемент (`dequeue`);
- `_tail` — куда дописываем новый (`enqueue`).

Если забрали последний элемент, очередь пустая: `_head` и `_tail` оба ставим
в `None`. Иначе следующий `enqueue` попытается дописать к уже удалённому узлу.

**Некорректный ввод.**  
`pop` / `peek` / `dequeue` на пустой структуре — это ошибка операции,
а не штатный ответ. Код бросает `IndexError`, а не возвращает `None` молча.

---

## 2. Оценка сложности

Все основные операции стека и очереди работают за **O(1)** по времени:
меняются одна-две ссылки и счётчик размера.

Дополнительная память на одну операцию — **O(1)**.  
На хранение `N` элементов нужно **O(N)** памяти (по одному узлу на значение).

Размер не считаем обходом списка: он лежит в поле `_size`.

## 3. Визуализация работы алгоритма

Нетривиальный разбор — с чередованием вставки и удаления

### Стек: `push(1), push(2), pop(), push(3)`

Старт: `_head = None`.

**push(1)**

```text
_head -> [1] -> None
```

**push(2)** — новый узел встаёт в начало:

```text
_head -> [2] -> [1] -> None
```

**pop()** → `2`

```text
_head -> [1] -> None
```

**push(3)**

```text
_head -> [3] -> [1] -> None
```

Дальше `pop()` даст `3`, затем `1`. Последний добавленный снимается первым.

### Очередь: `enqueue(1), enqueue(2), dequeue(), enqueue(3)`

**enqueue(1)** — один узел и голова, и хвост:

```text
_head -> [1] -> None  <- _tail
```

**enqueue(2)** — прицепляем к хвосту:

```text
_head -> [1] -> [2] -> None  <- _tail
```

**dequeue()** → `1`

```text
_head -> [2] -> None  <- _tail
```

**enqueue(3)**

```text
_head -> [2] -> [3] -> None  <- _tail
```

Дальше `dequeue()` даст `2`, затем `3`. Порядок как при добавлении.

### Очередь: забираем последний элемент

Это место, где легко забыть сбросить хвост.

```text
_head -> [7] -> None  <- _tail
dequeue() -> 7
_head = None, _tail = None
```

После этого `enqueue(8)` снова делает один узел и головой, и хвостом.
Если оставить старый `_tail`, новый элемент «прицепится» к уже удалённому узлу.

### Сравнение на одной последовательности `1, 2, 3`

| Структура | Как кладём              | Как забираем     | Что получим |
|-----------|-------------------------|------------------|-------------|
| Стек      | три `push`              | три `pop`        | `3, 2, 1`   |
| Очередь   | три `enqueue`           | три `dequeue`    | `1, 2, 3`   |
