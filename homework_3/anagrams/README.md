# Задача 2. Anagrams

## Условие

Дан список слов. Нужно сгруппировать их так, чтобы в одной группе
оказались все анаграммы.

Пример: `["eat", "tea", "tan", "ate", "nat", "bat"]`  
→ группы `bat`; `nat, tan`; `ate, eat, tea`.

Код: `solution.py`  
Тесты: `test_anagrams.py`

---

## 1. Объяснение решения

**Идея алгоритма.**  
Два слова — анаграммы, если из одних и тех же букв. Если отсортировать
буквы, получится один и тот же ключ: у `eat` и `tea` это `aet`.

Идём по списку. Для каждого слова считаем ключ `"".join(sorted(word))`
и кладём слово в группу с этим ключом. Группы храним в словаре
«ключ → список слов».

Порядок групп — по первому появлению ключа. Порядок слов внутри группы —
как во входе. На ответ это не влияет: условие порядок групп не фиксирует.

**Некорректный ввод.**  
Если в списке не строки — `TypeError`. Пустой список — штатный случай,
возвращаем `[]`.

---

## 2. Оценка сложности

Пусть `N` — число слов, `L` — длина самого длинного.

- **Время:** `O(N * L * log L)`.  
  Для каждого слова сортируем его буквы: `O(L log L)`, таких слов `N`.
  Вставки в словарь в среднем `O(1)`.

- **Память:** `O(N * L)`.  
  Храним все слова ещё раз в группах и ключи длины `L`.

Можно заменить сортировку на подсчёт букв за `O(L)` (массив на 26 позиций),
тогда время `O(N * L)`. Для общего случая со любыми символами сортировка проще.

## 3. Визуализация работы алгоритма

Разбор на примере из условия, но по шагам — видно, когда открывается
новая группа, а когда слово дописывается в старую.

Ключ = буквы слова по алфавиту.

| Шаг | слово | ключ | группы после шага                                      |
| --- | ----- | ---- | ------------------------------------------------------ |
| 1   | eat   | aet  | `aet: [eat]`                                           |
| 2   | tea   | aet  | `aet: [eat, tea]`                                      |
| 3   | tan   | ant  | `aet: [eat, tea]`; `ant: [tan]`                        |
| 4   | ate   | aet  | `aet: [eat, tea, ate]`; `ant: [tan]`                   |
| 5   | nat   | ant  | `aet: [eat, tea, ate]`; `ant: [tan, nat]`              |
| 6   | bat   | abt  | плюс `abt: [bat]`                                      |

Итог в порядке появления ключей:

```text
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

Другой короткий случай: `["ab", "ba", "abc"]`.

| Шаг | слово | ключ | группы                |
| --- | ----- | ---- | --------------------- |
| 1   | ab    | ab   | `[ab]`                |
| 2   | ba    | ab   | `[ab, ba]`            |
| 3   | abc   | abc  | `[ab, ba]` и `[abc]`  |
