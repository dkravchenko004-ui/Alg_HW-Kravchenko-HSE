# Задача 1. Two sum

## Условие

Дан массив целых чисел `arr` и число `k`. Нужно найти индексы двух элементов,
сумма которых равна `k`. Такая пара ровно одна. В ответ — два индекса
через пробел, по возрастанию.

Примеры: `[1, 3, 4, 10]`, `k = 7` → `1 2`; `[5, 5, 1, 4]`, `k = 10` → `0 1`.

Код: `solution.py`  
Тесты: `test_two_sum.py`

---

## 1. Объяснение решения

**Идея алгоритма.**  
Идём по массиву слева направо и помним, какие числа уже встречались
и на каком индексе. Для текущего `arr[i]` проверяем, видели ли мы
число `k - arr[i]`. Если да — пара найдена. Если нет — кладём `arr[i]`
в словарь и идём дальше.

Словарь здесь — хеш-таблица: поиск «нужного» числа занимает в среднем
константу, а не второй проход по массиву.

Один и тот же элемент дважды не берём: сначала смотрим, есть ли пара
среди *уже пройденных* индексов, и только потом записываем текущий.
Поэтому в `[5, 5]` при `k = 10` ответ `0 1`, а не «пятёрка сама с собой».

Индексы в ответе идут по возрастанию: найденный старый индекс всегда
меньше текущего `i`.

**Некорректный ввод.**  
Не список чисел или нецелое `k` — `TypeError`. Меньше двух элементов —
`ValueError`. Если пары нет (по условию такого быть не должно) —
тоже `ValueError`.

---

## 2. Оценка сложности

Пусть `N` — длина массива.

- **Время:** `O(N)`.  
  Один проход. Каждая проверка и запись в словарь в среднем `O(1)`.

- **Память:** `O(N)`.  
  В словаре в худшем случае почти все элементы, пока не найдётся пара.

Двойной цикл был бы `O(N^2)` по времени и `O(1)` по памяти. Для этой
задачи достаточно одного прохода.

---

## 3. Визуализация работы алгоритма

Разбор не из условия: `arr = [4, 1, 6, 3]`, `k = 9`.
Пара — `6 + 3`, индексы `2` и `3`.

Словарь `seen`: число → индекс.

| Шаг | i | arr[i] | ищем k − arr[i] | seen до шага      | Что происходит      |
| --- | - | ------ | --------------- | ----------------- | ------------------- |
| 1   | 0 | 4      | 5               | `{}`              | 5 нет, пишем 4 → 0  |
| 2   | 1 | 1      | 8               | `{4: 0}`          | 8 нет, пишем 1 → 1  |
| 3   | 2 | 6      | 3               | `{4: 0, 1: 1}`    | 3 нет, пишем 6 → 2  |
| 4   | 3 | 3      | 6               | `{4: 0, 1: 1, 6: 2}` | 6 есть на индексе 2 |

Ответ: `2 3`.

Пример из условия `[5, 5, 1, 4]`, `k = 10`:

| Шаг | i | arr[i] | ищем | seen     | Итог                |
| --- | - | ------ | ---- | -------- | ------------------- |
| 1   | 0 | 5      | 5    | `{}`     | себя ещё нет в seen |
| 2   | 1 | 5      | 5    | `{5: 0}` | нашли индекс 0      |

Ответ: `0 1`.
